POPTILES
Groups for your Windows taskbar. Click a group and a tile with its apps pops up.


GETTING STARTED
1. Open PopTiles from the Start menu.
2. Click "New group", enter a name and click "Create".
3. Windows asks at the bottom right whether the group should be pinned to the taskbar. Click "Yes". This can take a few seconds.
4. Add items: "Add app", "File", "Folder" or "Web address". You can also drag files and shortcuts into the list.

Windows requires this confirmation, so pinning can't be done without a click. Windows notifications must be turned on. If you missed the question, use "Pin to taskbar" to try again.


USING A TILE
- Click a group icon in the taskbar to open its tile.
- Click an item to start it. The tile then closes.
- Click next to the tile, press Esc or click the group icon again to close it.
- The gear in the tile opens the editor.


CHANGING A GROUP
- "Change icon" lets you choose a symbol and color, the icon of an item, an installed icon, or your own image (PNG, JPG, BMP, ICO). By default, the icon shows the first four items.
- Drag items in the list to change their order.
- "Layout" sets how items are arranged in the tile: automatic, one row, 2 to 4 columns or a list.
- Under "Change icon" you can pick a color or use "Custom color". It colors the symbol and the automatic icon. With "Also use this color for the tile", the tile gets the color too.
- "Display name" changes the name shown in the tile.
- Changes are saved automatically.


DELETING A GROUP
Select the group and click "Delete". Its icon is also unpinned from the taskbar. If that doesn't work, PopTiles tells you. In that case, right-click the icon in the taskbar and unpin it.


GOOD TO KNOW
- Groups only start programs. A running program still gets its own taskbar icon.
- PopTiles doesn't run in the background and doesn't start with Windows. It only runs while a tile or the editor is open.
- If you rename a pinned group, its taskbar icon may keep the old name until you pin it again.
- If the taskbar still shows an old icon after a change, sign out of Windows and back in.
- Web addresses get a letter tile. PopTiles doesn't download website icons.
- PopTiles follows your Windows display language: English, German, French, Spanish or Italian. For other languages it uses English.


WHEN SOMETHING DOESN'T WORK
- Windows doesn't ask about pinning: Check that notifications are turned on. If Windows doesn't allow pinning, PopTiles offers to show the shortcut in Explorer. Right-click it there and pin it to the taskbar yourself.
- "This group no longer exists": The group was deleted. Right-click the icon in the taskbar and unpin it.
- An app is missing from "Add app": The list contains the Start menu apps and games from Steam, Ubisoft Connect, Epic Games and GOG. Use "File" to add any other program.


WHERE YOUR DATA IS STORED
Program and groups: %LOCALAPPDATA%\Programs\PopTiles
Start menu entries: in the "PopTiles" folder

PopTiles doesn't send any data over the internet.


UNINSTALLING
Open Windows Settings > Apps > Installed apps and uninstall PopTiles. You'll be asked whether to delete your groups as well. Unpin any remaining icons from the taskbar yourself.


WINDOWS VERSION
PopTiles was developed and tested on Windows 11. On older versions, automatic pinning and the transparent tile background may not be available.
